# DayBy — тестовые сборки

Учебный проект. Сборки только UI, данные демонстрационные.

- [DayBy-1.0.0-arm64.apk](https://github.com/baiama/DayBy/raw/apk/DayBy-1.0.0-arm64.apk) — откройте ссылку на телефоне, скачайте и установите (разрешите установку из неизвестных источников).
- [DayBy-maestro-flows.zip](https://github.com/baiama/DayBy/raw/apk/DayBy-maestro-flows.zip) — сценарии Maestro: `adb install DayBy-1.0.0-arm64.apk`, распакуйте архив, `maestro test .maestro`.

Сборка соответствует коду ветки main, коммит 52d35c1.
