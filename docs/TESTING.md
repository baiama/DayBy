# DayBy: документация для тестирования

Версия сборки: **1.1.0** (Android, arm64 / armv7).
Сейчас это **UI-версия без бэкенда**. Все данные моковые и хранятся в памяти:
после перезапуска приложения задачи и списки возвращаются к демо-набору.
В `SharedPreferences` сохраняются только оформление, настройки и флаг «онбординг пройден».

Пакет приложения: `com.chotatam.dayby`.

---

## 1. Установка

```bash
adb install -r DayBy-1.1.0-arm64.apk     # большинство современных телефонов и эмуляторов arm64
adb install -r DayBy-1.1.0-armv7.apk     # старые 32-битные устройства
```

Эмулятор x86_64 эту сборку не запустит. Нужен arm64-образ (на Mac с Apple Silicon он используется по умолчанию) или реальное устройство.

## 2. Вход

Бэкенда нет, поэтому принимается **любая** почта и **любой** пароль, если они проходят проверку формата:

| Поле | Правило | Текст ошибки |
| --- | --- | --- |
| Почта | пустая или не похожа на `x@y.z` | «Введите почту» / «Неверный формат почты» |
| Пароль | короче 6 символов | «Минимум 6 символов» |
| Имя (регистрация) | пустое | «Введите имя» |

Имя пользователя в профиле берётся из части почты до `@` (для `tester@dayby.app` это `tester`).
Вход через Google, Facebook и X сразу пускает в приложение с профилем `User Name`.

## 3. Карта экранов

```
Сплэш (~1.8 с)
 ├─ Онбординг (3 слайда, только при первом запуске) → Вход
 └─ Вход ─┬─ Регистрация
          ├─ Восстановление пароля
          └─ Главная (вкладки внизу)
               ├─ Главная ── Поиск, Профиль ── Настройки ── О приложении
               ├─ Мои списки ── Экран списка
               ├─ Статистика
               └─ Календарь
             Тап по любой задаче → Детали задачи
             Кнопка «+» → редактор новой задачи (на «Статистике» её нет)
```

## 4. Демо-данные

Даты отсчитываются от текущего дня («сегодня» = день запуска).

| --- | --- | --- | --- | --- | --- | --- |
| 1 | Сдать отчёт по проекту | сегодня | Работа | ★ | ✓ | заметка, подзадачи 2/2 |
| 2 | Позвонить маме | сегодня | Личное | ★ | ✓ | |
| 3 | Купить продукты на неделю | сегодня | Покупки | ★ | ✓ | |
| 4 | Записаться к стоматологу | сегодня | Личное | ★ | | напоминание 18:00, заметка |
| 5 | Ответить на письма | сегодня | Работа | | | |
| 6 | Тренировка | завтра | Личное | ★ | | повтор еженедельно, напоминание 07:30 |
| 7 | Созвон с командой | завтра | Работа | | | |
| 8 | Молоко, хлеб, яйца | +2 дня | Покупки | | | подзадачи 1/3 |
| 9 | Подготовить презентацию | вчера | Работа | ★ | ✓ | |
| 10 | Прочитать главу книги | −2 дня | Личное | | ✓ | |
| 11 | Оплатить интернет | −3 дня | Личное | | ✓ | |

Списки: `work` 💼 Работа, `personal` 🌸 Личное, `shopping` 🛒 Покупки.

Чем можно проверить данные:
- Прогресс на главной сразу после входа: **60 %** (выполнено 3 из 5 задач на сегодня).
- Новые задачи получают id `100`, `101`, …, новые подзадачи `s100`, `s101`, …, новые списки `custom1`, `custom2`, …
  (общий счётчик у задач и подзадач: если сначала добавить задачу, первая подзадача получит `s101`).

## 5. Экраны и что проверять

### Онбординг
- Показывается один раз после сплэша. После «Пропустить» или «Начать» при следующем запуске сразу открывается вход.
- Чтобы увидеть онбординг снова, очистите данные приложения или переустановите его.
- Листается свайпом и кнопкой «Далее». На последнем слайде кнопка называется «Начать», а «Пропустить» скрыта.

### Главная
- Кольцо прогресса показывает долю выполненных задач на сегодня.
- Раздел «Важные задачи» и раздел «Остальные». Если важных задач нет, выводится «Нет важных задач на сегодня».
- Если на сегодня нет ни одной задачи, показывается пустое состояние «На сегодня планов нет» с кнопкой «Добавить задачу».
- Если все задачи на сегодня выполнены, появляется баннер 🎉 «Все задачи на сегодня выполнены».
- Галочка справа отмечает задачу и сразу пересчитывает прогресс.
- Свайп задачи влево удаляет её, внизу появляется snackbar «Задача удалена» с кнопкой «Отменить», которая возвращает задачу на прежнее место.
- Под названием задачи показываются значки: список, подзадачи `x/y`, время напоминания, повтор, наличие заметки.
- Лупа открывает поиск, аватар открывает профиль.

### Детали задачи
- Шапка: назад, ★ (важная), ✎ (открывает редактор), 🗑 (удаляет после подтверждения и возвращает назад).
- Карточка с названием и галочкой, статус «В процессе» или «Выполнено».
- Дата открывает date picker. Список выбирается в нижнем меню, есть вариант «Без списка».
- Напоминание выбирается в time picker (24 ч), крестик убирает его. Повтор: нет / каждый день / по будням / каждую неделю / каждый месяц.
- Подзадачи: добавляются через поле «Добавить подзадачу» (Enter), отмечаются галочкой, удаляются крестиком. Прогресс-бар и счётчик `x/y` обновляются.
- Заметка сохраняется при вводе.

### Редактор задачи (нижний лист)
- Пустое название не сохраняется. Можно задать дату, отметить «Важная» и выбрать список (повторный тап снимает выбор).

### Мои списки и экран списка
- Карточка списка показывает «N из M выполнено» или «Пока пусто».
- «Новый список» открывает ввод названия и выбор из 12 эмодзи, после сохранения сразу открывается созданный список.
- На экране списка есть шапка с кольцом процента и фильтр «все / активные / готовые».
- Задачи разбиты на группы: Просрочено, Сегодня, Завтра, Позже, Выполнено.
- Пустые состояния:
  - в пустом списке «Список пуст» с кнопкой «Добавить задачу», которая создаёт задачу сразу в этом списке;
  - в фильтре без результатов «Всё сделано!» или «Пока ничего не выполнено».
- Меню ⋮: «Переименовать», «Удалить выполненные», «Удалить список». После удаления списка его задачи остаются, но без списка.

### Поиск
- Ищет по названию, подзадачам и заметкам без учёта регистра.
- Фильтры: «Важные», «Невыполненные», один из списков. Их можно комбинировать с текстом запроса.
- Без запроса и фильтров показывается подсказка «Что ищем?». Если ничего не найдено, выводится «Ничего не нашлось».
- Над результатами стоит счётчик «N задач» с русскими окончаниями: 1 задача, 3 задачи, 5 задач.

### Календарь
- Полоса недели, стрелки переключают недели, «Сегодня» возвращает к текущему дню.
- Для дня без задач показывается пустое состояние с кнопкой «Добавить задачу», которая создаёт задачу на выбранную дату.

### Статистика
- Всего / выполнено / осталось и график за неделю.

### Профиль
- Изменение имени («Отмена» оставляет старое).
- «Уведомления», «Язык» и «Настройки» открывают экран настроек, «О приложении» открывает экран о приложении, «Выйти» возвращает на вход.
- Оформление: тема системная / светлая / тёмная, 6 акцентных цветов, размер текста. Всё это сохраняется после перезапуска.

### Настройки
- Переключатели: напоминания, звук (неактивен, если напоминания выключены), утренняя сводка и время сводки (неактивно, если сводка выключена).
- Начало недели, «Выполненные на главной» (если выключить, выполненные задачи пропадают с главной, а процент не меняется), напоминание по умолчанию.
- Язык Русский / English. **Сейчас меняется только подпись, интерфейс остаётся на русском.**
- «Удалить выполненные» спрашивает подтверждение. Если выполненных задач нет, показывается snackbar «Выполненных задач нет».
- Все настройки сохраняются после перезапуска.

### О приложении
- Версия и ссылки. Ссылки пока показывают snackbar «Скоро будет доступно».

## 6. С чего начать (для тех, кто учится)

1. Установите APK, пройдите онбординг и войдите. Потратьте 10 минут на то, чтобы просто «потыкать» каждый экран из раздела 5.
2. Напишите **ручные тест-кейсы** для одного экрана. Лучше начать с «Деталей задачи»: там много действий и предсказуемый результат. Шаблон:

   | Поле | Пример |
   | --- | --- |
   | ID | TC-TD-01 |
   | Название | Добавление подзадачи |
   | Предусловие | Выполнен вход, открыта задача «Ответить на письма» |
   | Шаги | 1. Тап по «Добавить подзадачу». 2. Ввести «Test». 3. Нажать Enter |
   | Ожидаемый результат | Подзадача «Test» появилась, счётчик показывает 0/1, поле очистилось |

3. Подумайте о **негативных и граничных случаях**:
   - пустое название задачи или списка;
   - пароль из 5 и из 6 символов;
   - очень длинный текст;
   - удаление последней задачи в списке;
   - поиск без результатов;
   - отмена в диалоге удаления.
4. Сравните поведение в **светлой и тёмной теме** и с **крупным текстом** (Профиль → Размер текста): ничего не должно обрезаться или наезжать.
5. Найденный баг оформите так: шаги воспроизведения, ожидаемый результат, фактический результат, скриншот, модель устройства и версия Android.
6. Переходите к **автотестам**: откройте готовый флоу, например `11_task_details.yaml`, прочитайте его рядом с приложением, запустите, а потом напишите свой флоу по своему же ручному тест-кейсу.

Идеи для своих первых флоу, которых ещё нет:
- задача в календаре на другой день появляется в нужной дате;
- кнопка «Отменить» после свайпа возвращает задачу;
- снятие фильтра «Невыполненные» в поиске;
- смена акцентного цвета сохраняется после перезапуска (`launchApp` без `clearState`).

## 7. Известные ограничения (не баги)

- Нет бэкенда: задачи, списки и профиль сбрасываются при перезапуске.
- Уведомления и напоминания не приходят, пока это только UI.
- «Начало недели» и «Напоминание по умолчанию» сохраняются, но ещё ни на что не влияют.
- Восстановление пароля и соцвход работают как заглушки.

## 8. Автотесты на Maestro

Готовые флоу лежат в архиве `DayBy-maestro-flows.zip` и в репозитории в папке `.maestro/`.

```bash
maestro test .maestro                            # все флоу
maestro test .maestro/flows/11_task_details.yaml # один флоу
```

| 02_social_login | вход через соцсети |
| 03_registration | регистрация |
| 04_forgot_password | восстановление пароля |
| 05_tasks | создать, отметить, переименовать через детали, удалить свайпом |
| 06_lists | открытие списков |

| 08_calendar | календарь |
| 09_profile | профиль, переходы в настройки и «О приложении», оформление, выход |
| 10_onboarding | слайды и то, что онбординг показывается один раз |
| 11_task_details | подзадачи, повтор, смена списка, выполнение, удаление |

Общие подфлоу:
- `subflows/launch.yaml`: запуск с очисткой данных, пропуск онбординга, ожидание экрана входа;
- `subflows/login.yaml`: вход под `tester@dayby.app` / `secret123`.

### Как искать элементы
- У всех интерактивных элементов есть стабильный id (`resource-id` на Android, `accessibilityIdentifier` на iOS). В Maestro его ищут через `id:`.
- У строки задачи название, список и значки собраны в один узел, поэтому проверяйте текст регуляркой: `"Ревью кода.*"`.
- Maestro на Android не умеет печатать кириллицу, поэтому в тестах вводите латиницу.
- Поля, где действие «готово», закрывайте `pressKey: Enter`.
